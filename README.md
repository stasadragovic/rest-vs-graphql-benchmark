# REST vs GraphQL benchmark

Aplikacija za upravljanje projektima (nalik Trello/Jira) razvijena za potrebe
diplomskog rada „Компаративна анализа перформанси REST и GraphQL технологија
у савременим веб системима“.

- `backend/` – Spring Boot (REST i GraphQL API)
- `frontend/` – React + TypeScript (Vite)
- `database/` – šema i testni podaci (PostgreSQL)
- `performance-tests/` – JMeter testovi
